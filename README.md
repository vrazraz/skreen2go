# Skreen2Go

Нативное macOS-приложение для скриншотов с аннотациями и записи экрана. Живёт в menu bar, без окна в Dock. Обработка полностью локальная — ни снимки, ни записи не покидают компьютер.

Полное описание поведения — в [PRD.md](PRD.md).

## Требования

- macOS 15+
- Swift 6.1+ (манифест SwiftPM использует формат 5.9; для universal/App Store-сборки нужен Xcode)

Единственная внешняя зависимость — [rive-ios](https://github.com/rive-app/rive-ios): она проигрывает
анимацию руки, которая появляется при копировании скриншота в буфер. Приходит бинарным
xcframework'ом, поэтому первая сборка тянет ~115 МБ; в готовое приложение попадает
`RiveRuntime.framework` весом около 15 МБ (universal).

## Сборка и запуск

```sh
swift build            # сборка
swift test             # тесты
./Scripts/build-app.sh # собрать dist/Skreen2Go.app для локального тестирования
open dist/Skreen2Go.app
```

Для универсального приложения, работающего на Apple Silicon и Intel Mac:

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
ARCHS=universal ./Scripts/build-app.sh
```

Версия и номер сборки берутся из файлов [`VERSION`](VERSION) и [`BUILD_NUMBER`](BUILD_NUMBER). Их можно временно переопределить переменными `APP_VERSION` и `APP_BUILD`.

Если исходные PNG иконки лежат в `~/Desktop/icons`, `.icns` можно воспроизвести так:

```sh
./Scripts/build-app-icon.sh
```

Для Intel-среза нужен установленный Xcode и принятая лицензия Xcode. Если система ещё не приняла её, выполните в Terminal команду `sudo xcodebuild -license accept` и подтвердите действие своим паролем администратора.

При первом запуске macOS запросит доступ к **записи экрана**. Без него захват работать не будет — приложение покажет объяснение и кнопку в системные настройки.

Доступ к **микрофону** запрашивается отдельно и только тогда, когда вы включите микрофон на панели перед записью.

> Скрипт подписывает бандл ad-hoc, поэтому после каждой пересборки разрешение на запись экрана может потребоваться выдать заново. Постоянная подпись это снимает.

## Подготовка к Mac App Store

Приложение уже содержит App Sandbox entitlements, privacy manifest и поддержку security-scoped bookmark для выбранной папки сохранения. Локальный скрипт по умолчанию использует ad-hoc подпись. Для App Store нужен Apple Developer Program, явный App ID `com.skreen2go.app`, distribution certificate и профиль **Mac App Store Connect**:

```sh
APP_STORE=1 \
ARCHS=universal \
SIGNING_IDENTITY="Mac App Distribution: Your Name (TEAMID)" \
PROVISIONING_PROFILE="$HOME/Downloads/Skreen2Go.provisionprofile" \
./Scripts/build-app.sh
```

Затем подготовьте подписанный пакет для Mac App Store:

```sh
INSTALLER_IDENTITY="Mac Installer Distribution: Your Name (TEAMID)" \
./Scripts/build-app-store-pkg.sh
```

Проверенный `.pkg` можно загрузить через Transporter. Иконка (`Resources/AppIcon.icns`), entitlements, privacy manifest и локализованные строки системных запросов уже в репозитории. Остаётся то, что делается в App Store Connect: privacy labels, описание, скриншоты, support URL и данные продавца. Не загружайте `dist/` и `.build/` в репозиторий — они исключены через `.gitignore`.

## Как пользоваться

Горячая клавиша по умолчанию — **⌃⇧S** (меняется в настройках).

**Выбор:** клик по окну берёт окно целиком, перетаскивание мышью — произвольную область. Рамка остаётся живой: её можно двигать изнутри и тянуть за восемь ручек.

**Панель** появляется рядом с рамкой сразу после отпускания мыши:

| | |
|---|---|
| ↗ □ Aa | стрелка, рамка, текст |
| ● | цвет — палитра из десяти цветов раскрывается под кнопкой |
| ↶ ↷ | отменить / повторить (⌘Z, ⇧⌘Z) |
| ⚙︎ | настройки |
| ⏺ 🔊 🎙 | записать видео, системный звук, микрофон |
| ⧉ ↓ ⤓ | копировать, сохранить, сохранить как… |
| ✕ | отмена (Esc) |

Цвет выбирается собственной палитрой, а не системным Color Picker: тот открывает окно на обычном уровне, которое оверлей уровня `.screenSaver` закрывает собой. В полном редакторе оверлея нет, поэтому там остаётся системный Color Picker со всем спектром.

Аннотации рисуются прямо поверх выделения и не выходят за его границы. **Enter** открывает полный редактор — там дополнительно есть инструмент выбора и перемещения, размытие, визуальный курсор, удаление объекта (⌫) и очистка всех аннотаций.

Файлы сохраняются как `Screenshot 2026-08-06 at 14.30.25.png` в папку из настроек (по умолчанию Downloads).

## Запись видео

Горячая клавиша — **⌃⇧R** (меняется в настройках). Она же останавливает запись, поэтому запомнить нужно одну комбинацию.

Область выбирается той же рамкой, что и для скриншота. Перед стартом на панели включаются нужные источники звука — системный и микрофон, независимо; выбор запоминается. Кнопка ⏺ запускает отсчёт 3-2-1, и только потом начинается запись.

Во время записи иконка в menu bar становится красной кнопкой остановки со счётчиком времени: клик по ней останавливает запись сразу. Готовый файл — `Recording 2026-08-24 at 14.30.25.mp4`, H.264, рядом со скриншотами. Клик по уведомлению открывает его в Finder; то же есть пунктом «Показать последнюю запись» в меню.

Отсчёт, уведомления и индикатор в кадр не попадают, как и звуки самого приложения.

Что запись пока не умеет: захватывать больше одного экрана за раз (область поперёк двух мониторов обрезается по тому, где её больше, о чём приложение сообщает), ставить паузу и накладывать аннотации.

## Настройки

Открываются шестерёнкой в панели или пунктом «Настройки…» в меню menu bar: горячие клавиши скриншота и записи, автозапуск, папка сохранения, формат (PNG или JPEG), язык интерфейса, цвет по умолчанию, толщина и прозрачность линий, размер и начертание текста, интенсивность размытия, курсор и подсветка кликов в записи, показ уведомлений и сброс к значениям по умолчанию.

Одну и ту же комбинацию нельзя назначить обеим горячим клавишам: они регистрируются системно, и одна из них просто не работала бы.

Язык интерфейса — «Системный», English или Русский. Выбранный язык применяется сразу, без перезапуска.

## Структура

```
Sources/Skreen2GoCore/       вся логика (библиотека, чтобы её можно было тестировать)
  AppDelegate.swift          menu bar, глобальный хоткей (Carbon)
  Capture.swift              оверлей выбора, панель действий, палитра цветов
  CaptureServices.swift      протокол захвата для внедрения зависимостей и тестов
  ScreenCaptureService.swift ScreenCaptureKit: окна, области, права доступа
  Editor.swift               полный редактор аннотаций
  AnnotationSession.swift    общая история Undo/Redo для оверлея и редактора
  RecordingServices.swift    швы записи, ошибки, временные файлы
  RecordingGeometry.swift    выбор дисплея, sourceRect, чётные размеры кадра
  ScreenRecordingService.swift SCStream и SCRecordingOutput
  RecordingController.swift  отсчёт, ход записи, сохранение результата
  RecordingCountdownPanel.swift панель 3-2-1
  ImagePipeline.swift        рендеринг, масштаб, кэш размытия, кодирование
  ScreenshotOutput.swift     буфер обмена, сохранение, «Сохранить как…»
  ScreenshotFileWriter.swift актор, уводящий запись файла с главного потока
  Models.swift               модель аннотаций, хранилище настроек
  Settings.swift             окно настроек, автозапуск
  Localization.swift         поиск строк и принудительная смена языка
  Toast.swift                подтверждение действия, вспышка захвата
  Resources/{en,ru}.lproj/   строки интерфейса
Sources/Skreen2Go/           точка входа
Resources/                   Info.plist, entitlements, privacy manifest, иконка
  {en,ru}.lproj/             InfoPlist.strings — тексты системных запросов macOS
Scripts/                     сборка .app, иконки и пакета для App Store
Tests/                       регрессионные тесты (swift-testing)
```

Две папки `Resources` — не дубль. `Sources/Skreen2GoCore/Resources` попадает в бандл SwiftPM, который читает только код приложения; `Resources/*.lproj` кладётся в сам `.app`, потому что системные диалоги вроде запроса на запись экрана macOS рисует сама и читает Info.plist, а не наши строки.

Тесты покрывают то, что ломалось: геометрия на нескольких мониторах, масштаб при экспорте, раскладка панели, обрезка аннотаций границами рамки, отмена асинхронного захвата, полнота обеих локализаций. Запись покрыта на подставных зависимостях — вся машина состояний, выбор дисплея и округление кадра проверяются без экрана, микрофона и настоящей записи.
