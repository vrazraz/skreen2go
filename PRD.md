# PRD: Mac-приложение для скриншотов и аннотаций

## 1. Общая концепция

Нативное приложение для macOS, работающее из menu bar. Пользователь запускает захват кликом по иконке или горячей клавишей, выбирает окно либо область экрана, добавляет аннотации и копирует или сохраняет результат.

Обработка изображений выполняется полностью локально.

## 2. Целевая платформа

- macOS 14+
- Apple Silicon
- Работа только из menu bar
- Без отдельного окна в Dock
- Запуск вместе с macOS
- Распространение для личного использования

## 3. Запуск захвата

Запуск возможен:

- кликом по иконке в menu bar;
- глобальной горячей клавишей;
- через пункт «Настройки» для изменения горячей клавиши.

После запуска экран затемняется, а приложение переходит в режим выбора.

## 4. Режимы выбора

Поддерживаются два режима.

### Выбор окна

- окно под курсором подсвечивается;
- клик выбирает окно целиком;
- захватывается только область окна;
- системный курсор не попадает в изображение;
- тени и внешние скругления окна не захватываются.

### Выделение области

- пользователь зажимает мышь;
- растягивает прямоугольную рамку;
- после отпускания мыши область фиксируется;
- поддерживается работа на нескольких мониторах.

Клавиша Esc отменяет текущий выбор.

## 5. Панель действий

После выбора окна или области появляется плавающая панель инструментов.

Приоритет размещения:

1. под выделенной областью;
2. справа;
3. сверху;
4. слева.

Панель появляется после отпускания мыши и исчезает после выполнения действия.

Основные действия:

- «Копировать»;
- «Сохранить» — автоматически в Downloads;
- «Сохранить как…» — открывает стандартное окно выбора файла;
- «Отмена».

После копирования или сохранения отображается короткое системное уведомление.

## 6. Инструменты аннотаций

Все добавленные элементы находятся внутри выбранной области и попадают в итоговое изображение.

### Стрелка

- рисуется перетаскиванием мыши;
- перемещается;
- изменяет длину и направление;
- удаляется;
- поддерживает цвет, толщину и прозрачность.

### Рамка

- создаётся перетаскиванием;
- изменяет размер;
- перемещается;
- удаляется;
- поддерживает цвет, толщину и прозрачность.

### Текст

- добавляется кликом по изображению;
- редактируется после создания;
- перемещается;
- изменяет размер области текста;
- удаляется;
- поддерживает цвет, размер/начертание и прозрачность.

### Размытие

- добавляется прямоугольной областью;
- область можно перемещать и изменять;
- применяется только внутри выбранной зоны;
- интенсивность размытия настраивается.

### Курсор

Курсор добавляется как отдельный объект поверх изображения.

Доступные типы:

- обычная стрелка;
- указательный палец;
- рука;
- текстовый курсор;
- курсор изменения размера;
- индикатор клика.

Для добавленного курсора доступны:

- перемещение;
- изменение размера;
- удаление.

Это визуальный курсор, а не фактический курсор пользователя во время захвата.

## 7. Редактирование

В панели инструментов доступны:

- выбор инструмента;
- выбор цвета через системный Color Picker;
- настройки толщины;
- настройки прозрачности;
- настройки текста;
- Undo;
- Redo;
- удаление выбранного объекта;
- очистка всех аннотаций;
- шестерёнка настроек;
- копирование;
- сохранение;
- отмена.

Все элементы ограничены границами выбранного скриншота.

## 8. Настройки

Настройки открываются через кнопку с шестерёнкой в панели инструментов. Они отображаются в модальном окне.

Разделы настроек:

- горячая клавиша;
- запуск вместе с macOS;
- папка сохранения, по умолчанию Downloads;
- формат изображения;
- цвет по умолчанию;
- толщина стрелки и рамки;
- прозрачность стрелки и рамки;
- размер и начертание текста;
- прозрачность текста;
- интенсивность размытия;
- показывать или скрывать уведомления;
- сброс настроек к значениям по умолчанию.

Основной формат — PNG. При необходимости можно добавить JPEG как дополнительный формат.

## 9. Формат файлов и имена

Файл по умолчанию сохраняется как:

`Screenshot 2026-08-06 at 14.30.25.png`

При копировании в буфер помещается готовое изображение со всеми аннотациями.

## 10. Разрешения macOS

При первом запуске приложение объясняет необходимость разрешения Screen Recording.

Если для работы глобальной горячей клавиши потребуется дополнительное разрешение macOS, приложение также показывает понятную инструкцию пользователю.

Скриншоты не отправляются на сервер и не покидают компьютер.

## 11. Критерии готовности MVP

Приложение считается готовым, если пользователь может:

- запустить захват из menu bar;
- запустить захват горячей клавишей;
- выбрать окно;
- выделить произвольную область;
- работать на нескольких мониторах;
- добавить стрелку, рамку, текст, размытие и визуальный курсор;
- изменить цвет, толщину, размер и прозрачность;
- переместить или удалить аннотации;
- отменить и повторить действия;
- скопировать результат в буфер;
- сохранить PNG в Downloads;
- выбрать другую папку через «Сохранить как…»;
- получить уведомление об успешном действии;
- изменить параметры через модальное окно настроек.
