# Skreen2Go для Windows

В ветке `windows-port` находится отдельное приложение для Windows 11. Код версии для macOS не изменён. Порт написан на C# и .NET 10: WPF отвечает за окна, Win32 — за горячие клавиши и выбор окон, ScreenRecorderLib — за запись MP4.

## Что работает

- Значок в области уведомлений и настраиваемые глобальные сочетания клавиш: `Ctrl+Shift+S` для снимка, `Ctrl+Shift+R` для начала и остановки записи.
- Снимок произвольной области на виртуальном рабочем столе. Щелчок выбирает границы верхнего окна под курсором.
- Редактор снимка: стрелка, рамка, текст, размытие и маркер курсора; выделение, перемещение, удаление, очистка, отмена и повторение.
- Копирование готового снимка в буфер, сохранение PNG/JPEG и «Сохранить как». Размер исходного изображения сохраняется.
- Запись выбранной области в H.264 MP4 после трёхсекундного отсчёта. Системный звук и микрофон настраиваются отдельно; курсор и подсветка нажатий — тоже. Область, пересекающая несколько мониторов, обрезается до одного монитора с уведомлением.
- Настройки в `%LOCALAPPDATA%\Skreen2Go\settings.json`: папка, формат, язык, сочетания клавиш, автозапуск, звук и параметры аннотаций. Английский и русский интерфейс.

## Сборка и запуск

Нужны Windows 11 x64 и .NET 10 SDK. Из корня репозитория в PowerShell:

```powershell
dotnet run --project Windows\Skreen2Go.Windows\Skreen2Go.Windows.csproj
dotnet run --project Windows\Skreen2Go.Windows.Core.Tests
```

Самодостаточная сборка, для запуска которой не нужен установленный .NET:

```powershell
dotnet publish Windows\Skreen2Go.Windows\Skreen2Go.Windows.csproj -c Release -r win-x64 --self-contained true -o dist\windows
```

Запустите `dist\windows\Skreen2Go.Windows.exe`. Приложение появится в области уведомлений. Собранный каталог нужно переносить целиком: рядом с `.exe` лежат необходимые библиотеки. Архив `dist\Skreen2Go-Windows-x64.zip` содержит тот же каталог. Подписанного установщика пока нет.

## Ограничения текущей версии

- Снимок окна вырезается из общего снимка рабочего стола. Если окно закрыто другим окном, закрытая часть не восстанавливается.
- Запись выбранного окна использует его область на экране на момент выбора. Если окно переместится, область записи останется на месте.
- Инструменты находятся в отдельном окне редактора после выделения. Встроенной панели поверх выделенной области, изменения рамки после отпускания мыши, анимаций и тоста после копирования пока нет.
- Оверлей WPF и конфигурация с мониторами разного DPI требуют дополнительной ручной проверки. Защищённое содержимое некоторые приложения не позволяют захватывать.
- Запись с системным звуком проверена локально; одновременная запись микрофона и системного звука на разных устройствах не проверена. Для ScreenRecorderLib может понадобиться Microsoft Visual C++ Redistributable.

Полный проект решения и ход реализации находятся в `docs/superpowers/`.
