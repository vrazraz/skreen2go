# Материалы для App Store Connect

Скриншоты листинга, по два на локализацию. В сборку не входят и никаким скриптом не
читаются — загружаются руками в App Store Connect.

```
ru/01-screenshots.jpg   «Удобные скриншоты и запись экрана»
ru/02-recording.jpg     «Выдели нужную часть экрана и записывай видео»
en/01-screenshots.jpg   Easy screenshots and screen recording
en/02-recording.jpg     Select the desired part of the screen and record video
```

Номер в имени — это порядок в листинге. Первый скриншот главный.

## Требования, которые легко нарушить

- **Размер только один из четырёх**: 1280×800, 1440×900, 2560×1600, 2880×1800.
  Не «примерно» — валидатор отклоняет всё остальное. Наши в 2560×1600.
- **Альфа-канал запрещён.** Здесь это не проблема, потому что JPEG его не имеет вовсе,
  но экспорт PNG из Figma оставляет канал даже там, где прозрачности нет: у прошлой
  версии этих же кадров минимальная альфа была 254 из 255 — картинка непрозрачная,
  а канал присутствовал, и такой файл отклоняется.
- Цветовое пространство — RGB. CMYK не принимается.

Проверить перед загрузкой:

```sh
sips -g pixelWidth -g pixelHeight -g hasAlpha -g space Marketing/AppStore/*/*.jpg
```

## Как их снимали

Не самим Skreen2Go: захват области исключает окна собственного процесса, поэтому рамка
выбора и панель инструментов в кадр не попадут. Нужен системный ⇧⌘4 или другое
приложение.
