# Материалы для App Store Connect

Скриншоты листинга. В сборку не входят и никаким скриптом не читаются — загружаются
руками в App Store Connect.

## Требования, которые легко нарушить

- **Размер только один из четырёх**: 1280×800, 1440×900, 2560×1600, 2880×1800.
  Не «примерно» — валидатор отклоняет всё остальное. Наши сделаны в 2560×1600.
- **Альфа-канал запрещён.** Экспорт из Figma оставляет его даже там, где прозрачности
  нет: у исходников минимальная альфа была 254 из 255, то есть картинка непрозрачная,
  но канал присутствовал. Такие файлы отклоняются. Здесь лежат уже сведённые.
- Порядок в имени файла — это порядок в листинге. Первый скриншот главный.

Проверить готовый файл:

```sh
sips -g pixelWidth -g pixelHeight -g hasAlpha Marketing/AppStore/ru/*.png
```

## Чего пока нет

Скриншоты сделаны только для русской локализации. Интерфейс приложения двуязычный, и
если в App Store Connect заводить английский листинг, для него нужен свой комплект —
русские надписи на карточках туда не годятся.

Снять их самим Skreen2Go не получится: захват области исключает окна собственного
процесса, поэтому рамка выбора и панель инструментов в кадр не попадут. Нужен системный
⇧⌘4 или другое приложение.
